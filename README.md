# D1 starter：从真实数据到一个可检查结果

本文件只说明 starter 操作、数据契约和 TODO 边界。完整学习路线回到 `../README.md`。

## 1. 复制 starter

不要修改课程原件。复制到 `student-work/day-01-titanic`，在 VS Code 打开副本。运行 `Get-Location` 和 `Get-ChildItem`，确认当前目录与关键文件。

## 2. 下载指定真实数据

页面：https://www.kaggle.com/datasets/hesh97/titanicdataset-traincsv

把指定内容放到：`data/raw/train.csv`。不改名、不生成替代、不提交原始大数据。

## 3. 先验证

```powershell
python train.py --check-data
```

预期：REAL DATA CHECK PASSED；rows: 891；survived_counts: {0: 549, 1: 342}。失败就停止模型路线，按 Kaggle 指南检查目录、文件名、解压层级和来源。

## 4. 安装和运行未修改起点

```powershell
python -m pip install -r requirements.txt
python train.py
```

记录基线与预期 TODO。导入错误、数据错误和文件损坏不是预期 TODO。

## 5. 学生任务

只完成 build_candidate，并在现有预处理后加入固定随机种子的 RandomForestClassifier。一次只改一个小范围，不改数据、划分、指标或测试来获得漂亮结果。

```powershell
python -m unittest discover -s tests -v
python train.py
```

## 6. 结果与错误分析

检查 metrics.json、errors.csv。保存基线与候选同条件比较、一个重要错误、一个不能支持的结论。任何保存数字都要能由 README 命令重新产生。

## 数据契约

- 使用者：准备历史展览、希望解释数据和模型局限的博物馆教育团队；
- 来源：https://www.kaggle.com/datasets/hesh97/titanicdataset-traincsv；
- 预期位置：`data/raw/train.csv`；
- 检查命令：`python train.py --check-data`；
- 使用边界：这是历史观察数据分析，不是现代救援分配工具，也不能证明某个特征导致生存；
- 主要风险：只看准确率；把相关性说成因果；编造乘客故事；让测试集参与训练或调参。

README 写完整运行路线；根目录放 `report.md`、`presentation.pptx` 和 `submission.json`。运行数据检查、测试、主程序、`git diff --check`，然后按 `../08-submission.md` 建立本日独立仓库。
